
**The six phases in sequence:**

**Phase 1 — Interfaces & setup.** You can't master Claude without using every surface: Claude.ai Projects, Claude Code in the terminal, Cowork for desktop automation, Chrome extension for browsing, Excel and PowerPoint agents. Each one is a different productivity multiplier.

**Phase 2 — Prompt engineering.** This is the highest-leverage skill, full stop. Better prompts compound across everything else you build. Master XML structuring, chain-of-thought, system prompt design, and iterative refinement.

**Phase 3 — API & developer skills.** This is your Enigmax foundation. The Messages API, tool use, RAG, evals, and batch processing are what separate prototype-builders from product-builders. The evals skill is especially critical — it's the single biggest differentiator between junior and senior AI engineers.

**Phase 4 — Agents & orchestration.** This is NexAgent territory. Claude agents, MCP servers, multi-agent systems, and production safety patterns. Once you can build agents that work reliably, you're in a different category of AI engineer.

**Phase 5 — Research & writing.** 10x your content output for The AI Stack and Enigmax documentation. Deep research, long-form writing workflows, document analysis, and data analysis.

**Phase 6 — Power-user skills.** Extended thinking, multimodal inputs, AI-powered Artifacts, prompt version control, and cost optimization. These are the 1% moves.

Start with Phase 1 and 2 in parallel — they have the fastest payoff and build the mental models you'll need for everything else.
